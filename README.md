# SPAYTCH

Tower Defense 2D em pixel art: o jogador posiciona e evolui dinossauros para impedir que ondas de criaturas alcancem os ovos e o ninho. O projeto usa Godot 4.7 e mantém a visão de design e o roadmap em `docs/`.

O roadmap registra fundação Godot, grid e validação de mapas, Vale dos Ovos, caminho e movimento de inimigos, torres/dinossauros, primeiro loop jogável, UI/UX inicial, arte original, efeitos e integração. ## Executar

Abra `game/project.godot` no Godot 4.7.2. O projeto pode ser executado pelo editor Godot; as verificações headless descritas no roadmap estão nos arquivos em `game/tests/`.
